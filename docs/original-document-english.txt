⦁ Description of the Subject Area 
Taxi companies play an important role in modern urban transportation by providing an individualised and flexible service for moving people. Managing such a company involves a complex set of activities related to coordinating drivers, serving customers, maintaining the vehicle fleet, planning routes, preparing schedules, and keeping records. To achieve greater efficiency and competitiveness, a modern information system is needed to manage these processes.
The taxi company management information system aims to automate core business activities and make employees' daily work easier. It includes modules for registering and tracking customer orders in real time, managing driver and vehicle data, and automatically assigning requests according to taxi location and availability. Integration with GPS and mobile technologies enables route optimisation and reduces service time.
In addition to operational benefits, the system provides analytical tools for generating reports, analyses, and statistics that support management in making strategic decisions. It improves communication between dispatchers, drivers, and customers, raises service quality, and minimises human-error-related mistakes. In the long term, such a system contributes to the sustainable development and digitalisation of taxi services.

The mandatory requirements are: 
   -Reliability and security: The information system must protect customers' and drivers' personal data by using secure methods for storing and accessing information.
-Multi-role access: The system must support different roles—administrator, customer, and driver—with clearly defined permissions for each role.
-Database support: A database must be implemented to store all relevant data, including requests, routes, taxis, users, and other information.
-Orders and routes: The system must support ride requests, route creation, and automatic fare calculation based on the selected tariff.
-Payment processing: Different payment methods (cash, card, and e-wallet) must be supported, along with the ability to view payment history.
-Оценки и обратна връзка: Customerите трябва да могат да оставят оценка и коментар за всеки завършен курс.
-Tariff module: The system must allow prices to be configured according to time of day, distance, service type, and other factors.
-Tracking and reporting: Reports should be available for all completed rides, active drivers, workload, and revenue.

Customer:
– Съхранява информация за клиентите на таксиметровата компания.
– Включва идентификационен номер на клиента (client_id), име на клиента (име), телефонен номер (телефон), имейл (имайл) и адрес на клиента (клиент).
Driver:
– Съхранява информация за всички шофьори в системата.
– Включва идентификационен номер на шофьора (driver_id), име (име), телефонен номер (телефон),дата на назначаване (дата_назначаване) и статус(статус).
Taxi vehicle:
– Stores information about taxi vehicles.
– Includes the vehicle ID (car_id), registration number, make (марка), model (модел), year of manufacture (година), fuel type (тип_гориво), and current driver (driver_id).


Order:
– Съхранява информация за поръчките на такси.
– Включва идентификационен номер на заявката (order_id), идентификационен номер на клиента (client_id), идентификационен номер на маршрута (route_id), идентификационен номер на шофьора (driver_id), дата и час на поръчката (дата_и_час_на_поръчка), адрес на взимане (начален_адрес), адрес на дестинация(краен_адрес), разстоянието от началото до края (разстояние), продължителност на пътуването (продължителност) и статус на заявката (статус).
Route:
– Съхранява информация за маршрути, използвани при изпълнение на поръчки.
– Включва идентификационен номер на маршрута (route_id), начална точка (начален_адрес), крайна точка (краен адрес), разстояние (разстояние), и приблизително време (средна_продължителност).
Payment:
– Съхранява информация за плащанията, извършени от клиентите.
– Включва идентификационен номер на плащането (payment_id), идентификационен номер на поръчката (order_id), сума (сума), дата на плащане (дата_на_плащане) и метод на плащане (начин_на_плащане).
Review and comment:
– Stores customer ratings and comments about a particular order or driver.
– Includes the review ID (review_id), customer (client_id), driver (driver_id), order (order_id), rating (оценка), date (дата), and text comment (коментар).
Pricing:
– Съхранява информация за ценообразуването на услугите.
– Включва идентификационен номер на тарифа (tariff_id), тип услуга (service_type), цена на километър (price_per_km), минимална цена (minimum_price), допълнителни такси (extra_fees) и времеви диапазон на валидност (valid_time_range).


•	Database Creation Code
Once this information has been defined, the database itself must be created: 
CREATE TABLE Customerи (
    client_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    име VARCHAR2(100),
    телефон VARCHAR2(20),
    имейл VARCHAR2(100),
    адрес VARCHAR2(200)
);

CREATE TABLE Driverи (
    driver_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    име VARCHAR2(100),
    телефон VARCHAR2(20),
    дата_назначаване DATE,
    статус VARCHAR2(50)
);


CREATE TABLE Pricing (
    tariff_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    описание VARCHAR2(100),
    цена_на_км NUMBER(6,2),
    начална_такса NUMBER(6,2),
    валидна_от DATE,
    валидна_до DATE 
);

CREATE TABLE Vehicleи (
    car_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    регистрационен_номер VARCHAR2(20),
    модел VARCHAR2(50),
    марка VARCHAR2(50),
    година NUMBER(4),
    тип_гориво VARCHAR2(20),
    driver_id NUMBER,
    CONSTRAINT fk_автомобили_шофьори FOREIGN KEY (driver_id) REFERENCES Driverи(driver_id)
);



CREATE TABLE Routeи (
    route_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    начален_адрес VARCHAR2(200),
    краен_адрес VARCHAR2(200),
    разстояние NUMBER(6,2),
    средна_продължителност NUMBER(5,2)
);

CREATE TABLE Поръчки (
    order_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    client_id NUMBER,
    driver_id NUMBER,
    tariff_id NUMBER,
    route_id NUMBER,
    дата_и_час_на_поръчка TIMESTAMP,
    начален_адрес VARCHAR2(200),
    краен_адрес VARCHAR2(200),
    разстояние NUMBER(6,2),
    продължителност NUMBER(5,2),
    статус VARCHAR2(50),
    CONSTRAINT fk_поръчки_клиенти FOREIGN KEY (client_id) REFERENCES Customerи(client_id),
    CONSTRAINT fk_поръчки_шофьори FOREIGN KEY (driver_id) REFERENCES Driverи(driver_id),
    CONSTRAINT fk_поръчки_цени FOREIGN KEY (tariff_id) REFERENCES Pricing(tariff_id),
    CONSTRAINT fk_поръчки_маршрути FOREIGN KEY (route_id) REFERENCES Routeи(route_id)
);

CREATE TABLE Плащания (
    payment_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    order_id NUMBER,
    начин_на_плащане VARCHAR2(30),
    сума NUMBER(10,2),
    дата_на_плащане DATE,
    CONSTRAINT fk_плащания_поръчки FOREIGN KEY (order_id) REFERENCES Поръчки(order_id)
);

CREATE TABLE Оценки_и_коментари (
    review_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    client_id NUMBER,
    driver_id NUMBER,
    order_id NUMBER,
    оценка NUMBER(1),
    коментар VARCHAR2(500),
    дата DATE,
    CONSTRAINT fk_ревю_клиенти FOREIGN KEY (client_id) REFERENCES Customerи(client_id),
    CONSTRAINT fk_ревю_шофьори FOREIGN KEY (driver_id) REFERENCES Driverи(driver_id),
    CONSTRAINT fk_ревю_поръчки FOREIGN KEY (order_id) REFERENCES Поръчки(order_id)
);

Data Retrieval Queries: 
1.	Display all customers who have placed at least one order.
2.	Display all drivers with their phone numbers and hiring dates.
3.	Show all vehicles, including registration number, model, and make.
4.	Display all active tariffs with their descriptions, price per kilometre, and initial fee.
5.	Display orders placed on a specific date, including the customer, driver, pickup location, and destination.
6.	Show all routes with their starting addresses, destination addresses, and distances.
7.	Display all payments with the amount, payment method, and date.
8.	Show customers who gave a particular driver a rating below 3.
9.	Display orders and their statuses, filtered by the status "Completed".
10.	Show all orders for a given driver and customer, including trip distance and duration.
11.	Display all taxis (vehicles) and their drivers for completed rides.
12.	Show all tariffs that were valid during a specific period.
13.	Display a driver's average rating based on all their reviews.
14.	Display all drivers with ratings above 4.5.
15.	Display all orders completed during the last week, including customer information.
